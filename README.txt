展品相機對準測試 v3

這版針對實機測試修正：

1. 語音不再跳針
   - 舊版每次影像更新都 cancel() 正在說的句子。
   - v3 改成語音佇列：一句完整說完才說下一句。
   - 新判斷只會清除「尚未播放」的舊提示，不會切掉正在講的句子。

2. 增加展品在左右附近時的探索提示
   三階段：
   A. 沒有可靠候選：
      「目前鏡頭範圍內尚未確認展品……」
   B. 有穩定的疑似候選：
      「左側疑似有展品……」
      「右側疑似有展品……」
      也可能提示上方、下方。
   C. 正式確認：
      「已偵測到第一件展品……」
      然後才做精確左/右/上/下導引。

3. 成功對準後停止分析提示
   - 「很好，展品已接近鏡頭中央。請保持手機穩定。」
   - 「已對準第一件展品。展品定位完成。」
   - 之後不再重複這兩句。
